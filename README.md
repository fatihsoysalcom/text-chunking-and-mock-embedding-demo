# Text Chunking and Mock Embedding Demo

This example demonstrates the core concepts of 'chunking' and 'embedding' as used in Retrieval-Augmented Generation (RAG) systems. It takes a long text, splits it into smaller, overlapping chunks, and then generates a mock numerical vector (embedding) for each chunk. This illustrates how text is prepared for semantic search and retrieval.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
